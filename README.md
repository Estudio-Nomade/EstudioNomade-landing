# ESTUDIO NÓMADE

### Diseño y código en movimiento

---

Estudio de software premium especializado en productos digitales. Construimos aplicaciones, plataformas SaaS y sistemas que resuelven problemas de negocio con tecnología de vanguardia.

## Stack

| Frontend | Backend | Mobile | Infra |
|---|---|---|---|
| React | Node.js | React Native | Docker |
| Next.js | Supabase | Expo | Vercel |
| TypeScript | PostgreSQL | | GitHub |

## Estructura del proyecto

```
src/
├── app/            # App Router (layout, page)
├── components/     # Componentes reutilizables
│   ├── ui/         # Shadcn/ui + custom
│   ├── effects/    # Animaciones y partículas
│   ├── navbar/     # Navegación
│   ├── hero/       # Sección principal
│   ├── services/   # Servicios
│   ├── projects/   # Proyectos + mockups
│   ├── tech/       # Stack tecnológico
│   ├── process/    # Proceso de trabajo
│   ├── cta/        # Call to action
│   └── footer/     # Footer
├── hooks/          # Hooks personalizados
├── lib/            # Utilidades
└── constants/      # Datos del sitio
```

## Desarrollo

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # Build de producción
npm run lint    # ESLint
```

## Diseño

- **Dark theme** con gradientes violetas
- Glassmorphism y glow effects
- Tipografía: Inter (texto) + Space Grotesk (títulos)
- Animaciones con Framer Motion
- Responsive: desktop, tablet, mobile
